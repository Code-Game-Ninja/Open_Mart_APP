# Privacy Policy for AppMart

**Last updated: January 9, 2026**

## Introduction

Welcome to AppMart! This privacy policy explains how we handle your information when you use our mobile application to browse and discover GitHub repositories.

## Information We Collect

**AppMart does NOT collect, store, or transmit any personal data to our servers.**

### Local Data Storage
- **Favorite Repositories**: When you mark repositories as favorites, this data is stored locally on your device using AsyncStorage
- **No Cloud Sync**: Your favorites are never uploaded to our servers or any cloud service
- **No User Accounts**: We don't require sign-up, so we don't collect email, name, or any personal information

## How We Use Data

Since we don't collect data, we don't use, share, or sell any personal information.

### Local Storage Only
- All favorite repositories remain on your device
- No data leaves your device unless you explicitly configure a GitHub token
- No analytics or tracking

## Third-Party Services

AppMart uses the GitHub API to fetch public repository information:
- **GitHub API**: We make requests to `api.github.com` to retrieve public repository data
- **GitHub Token** (Optional): If you provide a GitHub Personal Access Token, it's stored locally in your device and used only for API requests
- Please review GitHub's Privacy Policy: https://docs.github.com/site-policy/privacy-policies

## Permissions

AppMart requests the following Android permissions:
- **INTERNET**: Required to fetch repository data from GitHub's API
- **ACCESS_NETWORK_STATE**: To check if the device has an internet connection

## Data Security

- All data is stored locally on your device
- No data is transmitted to external servers (except GitHub API requests)
- Your GitHub token (if provided) is stored securely on your device

## Data Deletion

You can delete all data at any time by:
1. Clearing favorites within the app (using "Clear All" button)
2. Clearing app data from Android Settings → Apps → AppMart → Clear Data
3. Uninstalling the app

## Children's Privacy

AppMart does not knowingly collect information from anyone under 13 years of age. Since we don't collect any personal information, the app is safe for all ages.
